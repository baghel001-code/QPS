# VMM_QPS database schema

Source: `Database/qps.sql` (SQL Server, SSMS export, `GO` batches; schemas `dbo`, `asn`, `auth`).
The script has no `USE` / `CREATE DATABASE`: create `VMM_QPS` first and run with `-d VMM_QPS`.

```bash
sqlcmd -S <server> -E -Q "IF DB_ID('VMM_QPS') IS NULL CREATE DATABASE VMM_QPS"
sqlcmd -S <server> -E -d VMM_QPS -b -i Database/qps.sql
```

Schema only: all 127 `INSERT`s are inside procedures, so every table starts with 0 rows.

- **FK columns without an index (26 of 33):** INSPECTIONS ×10, INSPECTION_REQUESTS ×3, QPS_PPS_LOGS ×2, FACTORY_AUDIT_REQUEST_CHECKLIST ×2, VENODR_EXCEL_DETAILS ×2, QPS_PPS_REQUEST.BUYER_ID, USER_MASTER.REGION_ID, QPS_USER_ROLES.ROLE_ID, MASTER_HIERARCHY.REPORTING_EMP_ID, AUDIT_ATTACHMENT_RESPONSE.ITEM_ID, asn.POIR_ASN_REQUEST.INSPECT_ID, VENDOR_ADDRESS1.VENDOR_ID.
- **Missing FKs on live tables:** VENDOR_ADDRESS.VENDOR_ID, AUDIT_*.AUDIT_ID, AUDIT_REPORT.STATUS_ID/GRADE_ID/AUDIT_REQ_ID, MASTER_AUDIT_CHECK_POINT.ELEMENT_ID, USER_ROLE_DETAILS.USER_ID/MENU_ID, EMAILRECIPIENTS.EMAILID.
- **Nullable but likely required (47 columns):** e.g. USER_MASTER.EMP_MAIL_ID/ROLE_ID, VENDORS_MASTER.CREATED_DATE, INSPECTIONS.CREATED_DATE, INSPECTION_REQUESTS.REGION_ID/STATUS_CODE/INSPECTION_TYPE_ID, EMAILRECIPIENTS.EMAILID, POHEADER.BUYER_ID.
- **Inconsistent types:** AUDIT_ID and INSPECTION_ID int vs bigint; VENDOR_CODE vc(20/30/50); BUYER_ID vc(20/50); USER_ID int vs vc(50); COLOR_CODE int vs vc(50); timestamps mix datetime/datetime2/datetimeoffset.
- **Naming / duplicates:** misspellings VENODR_EXCEL_DETAILS, INSPECITON_ID, RESEAN_FOR_FAIL, OPRATION_BY, TESTDESHBOARDLIST; `auth` uses PascalCase, the rest UPPER_SNAKE; two role systems (ROLE_MASTER and QPS_ROLES); leftover copies VENDORS_MASTER1 and VENDOR_ADDRESS1.
- **Sensitive data:** VENDORS_MASTER.PASSWORD (hashed by the app, but not enforced by the schema); API_MASTER.API_PWD and API_AUTHORIZATION (reversibly encoded or plain); USER_ACTIVE_SESSION.SESSION_TOKEN stored unhashed.
- **Questionable keys:** BSR_FILTER_DATA has a 6-column PK including `numeric` MRP; INSPECTOR_ASSIGNMENTS uses INSPECTION_DATE as its PK (one row per date).
